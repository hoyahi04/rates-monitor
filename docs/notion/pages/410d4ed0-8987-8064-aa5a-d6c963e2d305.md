# 미국 국채 가상 포트폴리오 모니터링 대시보드

## 1. 개요

<b>실제 미국 국채 종목을 대상으로 가상 매매하는 벤치마크 대비 액티브 운용 대시보드</b>를 구축한다.

실제 종목의 만기·쿠폰·발행잔액과 시장 수익률곡선을 사용하고, 투자금액·보유수량·거래는 가상으로 설정한다. 시장 변화가 포트폴리오의 위험과 성과에 미치는 영향을 분석하는 것이 목적이다.

<quote>
<b>핵심 질문</b>

미국 국채의 중간 만기 비중을 확대했을 때, 벤치마크 대비 어떤 위험을 부담하며 성과 차이는 어디에서 발생하는가?
</quote>

### 분석 흐름

<b>시장 모니터링 → 투자 판단 → 포지션 구성 → 위험 측정 → 성과분해 → 리밸런싱</b>

### 가격 평가 원칙

- GSW 제로 커브를 이용해 채권의 미래 현금흐름을 할인한다.
- 계산한 가격은 실제 거래가격과 구분하여 \*\*‘모델 평가가격’\*\*으로 표시한다.
- 포트폴리오와 벤치마크에 동일한 평가 방식을 적용한다.
- 초기 성과는 모델 기반 모의운용 결과이며, 실제 체결 성과와 구분한다.

## 4. 자체 벤치마크 설계

### 구성 방식

MSPD의 종목별 발행잔액과 종목 정보를 활용해 \*\*‘자체 미국 국채 벤치마크’\*\*를 만든다.

- 투자 조건에 부합하는 전체 종목을 포함한다.
- 발행잔액에 모델 평가가격을 곱한 시장가치를 기준으로 가중한다.
- 구성 종목과 기준 수량은 월별로 재설정한다.
- 재구성 사이에는 가격과 현금흐름에 따라 비중이 자연스럽게 변한다.
- 쿠폰·현금·편출 종목 처리 규칙을 명시하여 총수익을 계산한다.

### 비중 계산

<b>종목 시장가치 = 발행 액면잔액 × Dirty Price ÷ 100</b>

<b>벤치마크 종목 비중 = 해당 종목 시장가치 ÷ 전체 편입 종목 시장가치 합계</b>

Dirty Price는 경과이자를 포함한 가격이며, 액면 100당 가격을 사용한다.

### 데이터 시점 관리

MSPD의 <b>자료 기준일과 실제 발표일을 구분</b>한다. 과거 시뮬레이션에는 해당 시점에 공개되어 있던 자료만 사용한다.

월말 발행잔액을 같은 월말에 이미 알고 있었다고 가정하지 않는다. 재구성 시점에는 최신 공개 자료를 사용하고, 그 기준일을 함께 기록한다.

## 5. 비교할 포트폴리오

첫 구현에서는 벤치마크와 두 개의 가상 포트폴리오를 비교한다.

| 구분 | 구성 | 분석 목적 |
| --- | --- | --- |
| <b>자체 벤치마크</b> | 투자 가능 전체 종목을 시장가치로 가중 | 비교 기준 |
| <b>중립 복제 포트폴리오</b> | 대표 종목 12\~20개로 벤치마크 비중·KRD를 최대한 재현 | 표본 복제 오차 확인 |
| <b>벨리 확대 포트폴리오</b> | 중립 포트폴리오에서 중간 만기 위험을 확대 | 커브 전략 효과 분석 |

중립 포트폴리오도 일부 종목만 보유하므로 벤치마크와 완전히 같지 않다. 따라서 다음을 구분한다.

- <b>중립 포트폴리오 − 벤치마크:</b> 표본 복제에 따른 성과 차이.
- <b>벨리 확대 − 중립 포트폴리오:</b> 액티브 전략에 따른 추가 성과 차이.

### 만기 구간

| 잔존만기 구간 | 중립 포트폴리오 | 벨리 확대 예시 |
| --- | --- | --- |
| 1년 이상\~3년 미만 | 벤치마크에 맞춤 | 일부 축소 |
| 3년 이상\~5년 미만 | 벤치마크에 맞춤 | 유지 |
| 5년 이상\~7년 미만 | 벤치마크에 맞춤 | 확대 |
| 7년 이상\~10년 미만 | 벤치마크에 맞춤 | 확대 |
| 10년 이상\~20년 미만 | 벤치마크에 맞춤 | 일부 축소 |
| 20년 이상 | 벤치마크에 맞춤 | 일부 축소 |

각 구간에서 만기와 쿠폰을 분산해 대표 종목을 선정한다. 발행잔액은 선정 기준으로 활용하되 유동성 자체로 해석하지 않는다.

<b>보유 종목을 분류하는 만기 버킷과 금리 민감도를 측정하는 KRD 노드는 구분한다.</b> 쿠폰채는 여러 시점에 현금흐름이 발생하므로 한 종목의 위험이 여러 KRD 노드에 걸쳐 나타날 수 있다.

## 6. 투자 의견과 위험 한도

### 투자 의견의 구분

| 투자 의견 | 표현 방식 | 주요 확인 지표 |
| --- | --- | --- |
| 금리 하락 예상 | 전체 듀레이션 확대 | 액티브 듀레이션, DV01 |
| 금리 상승 예상 | 전체 듀레이션 축소 | 액티브 듀레이션, DV01 |
| 벨리 상대가치 매력 | 전체 듀레이션은 비슷하게 유지하고 벨리 KRD 확대 | 액티브 KRD |
| 장기 구간 부담 | 장기 KRD 축소, 다른 구간으로 재배분 | 장기 위험 기여도 |

<b>벨리 비중 확대와 듀레이션 확대를 구분한다.</b> 순수 커브 전략을 비교할 때는 전체 듀레이션 차이를 가능한 한 작게 유지한다.

### 초기 시스템 검증용 한도

| 지표 | 초기 가정 |
| --- | --- |
| 액티브 듀레이션 | 벤치마크 대비 ±0.5년 이내 |
| 만기 구간별 액티브 비중 | ±5%p 이내 |
| 현금 비중 | 0\~2% |
| 공매도·레버리지 | 사용하지 않음 |

<p>
위 한도는 최적 운용값이 아니라 설계 가정이다.
</p>

듀레이션 중립 커브 전략에는 별도로 더 좁은 허용오차를 설정한다.

## 7. 데이터와 거래 장부

현재 보유 비중을 덮어쓰는 방식 대신, 거래와 현금흐름을 누적해 보유내역을 재구성한다.

| 데이터 | 주요 항목 |
| --- | --- |
| <b>종목 정보</b> | CUSIP, 발행일, 만기일, 쿠폰, 지급 일정, 발행잔액 |
| <b>시장 데이터</b> | 날짜, GSW 커브, 주요 만기 금리, 데이터 출처·공개 시점 |
| <b>거래 장부</b> | 거래일·결제일, CUSIP, 매수/매도, 액면금액, 가격, 경과이자, 비용 |
| <b>현금 장부</b> | 초기 자금, 매매 결제대금, 쿠폰, 원금 상환, 비용 |
| <b>일별 평가</b> | 보유 액면, 평가가격·금액, 현금, NAV, 듀레이션, DV01, KRD |
| <b>벤치마크 이력</b> | 적용일, 구성 종목, 기준 수량·비중, 원천 자료 기준일 |
| <b>투자 판단 기록</b> | 판단 시점, 근거, 목표 포지션, 재검토 조건 |

### 투자 판단 기록 예시

> 벨리의 캐리·롤다운이 상대적으로 매력적이라고 판단하여 5\~10년 구간을 확대한다. 전체 액티브 듀레이션은 0에 가깝게 유지하고, 다음 월간 리밸런싱에서 판단을 재검토한다.

이를 통해 투자 당시 의도와 실제 성과 발생 원인을 비교한다.

## 8. 가격 평가와 성과분해

### 공통 평가 엔진

포지셔닝·성과분해·위험 분석에서 동일한 현금흐름 및 가격 계산 함수를 사용한다.

- 쿠폰과 원금의 지급 일정을 생성한다.
- GSW 제로 커브로 현금흐름을 할인한다.
- Clean Price와 경과이자, Dirty Price를 구분한다.
- 보유 채권 평가액과 현금을 합산해 NAV를 계산한다.
- 거래·결제·쿠폰의 반영 시점을 일관되게 적용한다.

### 손익 분해

<b>총손익 = 캐리·롤다운 + 평행 금리 이동 효과 + 커브 형태 변화 효과 − 거래비용 + 잔차</b>

| 항목 | 의미 |
| --- | --- |
| 캐리·롤다운 | 전일 곡선이 잔존만기 기준으로 유지된다는 가정에서 시간 경과와 지급 현금흐름이 만드는 손익 |
| 평행 금리 이동 효과 | 사전에 정의한 평행 이동 성분에 따른 손익 |
| 커브 형태 변화 효과 | 비평행 금리 변화에 따른 손익 |
| 거래비용 | 매매에 따른 가정 비용 |
| 잔차 | 볼록성·교차효과·근사오차 등 분해 방식으로 설명하지 못한 부분 |

캐리·롤다운에 쿠폰이 포함되면 쿠폰 수익을 다시 더하지 않는다. 초기에는 캐리와 롤다운을 묶어 계산하고, 이후 분리한다.

포트폴리오와 벤치마크를 같은 방식으로 분해한 뒤 차이를 계산하여 <b>초과수익의 원인</b>을 보여준다.

---

## 9. 위험 분석

| 지표 | 의미 |
| --- | --- |
| 듀레이션 | 금리 변화에 대한 가격 민감도 |
| DV01 | 금리 1bp 변화에 대한 가치 민감도를 금액으로 표시 |
| KRD | 특정 만기 지점의 금리 변화에 대한 민감도 |
| 액티브 KRD | 포트폴리오 KRD − 벤치마크 KRD |
| 사전적 Tracking Error | 현재 액티브 위험 노출과 금리 변화 공분산으로 추정한 초과수익 변동성 |
| 사후적 Tracking Error | 실제 누적된 초과수익 시계열로 계산한 변동성 |

KRD를 계산할 때는 금리 충격의 크기, 노드, 보간 방법을 고정한다. Tracking Error 계산에서는 금리 변화의 단위와 연율화 기준을 일치시킨다.

### 시나리오

- 전 구간 금리 ±25bp·±50bp.
- 단기금리만 상승 또는 하락.
- 장기금리만 상승 또는 하락.
- Steepening·flattening.
- 벨리 금리만 상대적으로 상승 또는 하락.

각 시나리오는 노드별 충격값을 명시하고, <b>민감도 근사 손익과 전체 현금흐름 재평가 손익</b>을 비교한다.

## 11. 구현 순서와 검증

| 단계 | 구현 내용 | 완료 기준 |
| --- | --- | --- |
| <b>1. 데이터 기반</b> | 종목 정보, GSW, MSPD 수집 | 기준일·공개일·단위 확인 |
| <b>2. 평가 엔진</b> | 현금흐름, 가격, 경과이자, 듀레이션·KRD | 가격과 민감도 계산 검증 |
| <b>3. 중립 포트폴리오</b> | 자체 벤치마크와 대표 종목 포트폴리오 | 복제 오차와 위험 차이 확인 |
| <b>4. 위험 화면</b> | 액티브 노출, 시나리오, Tracking Error | 충격별 손익 방향·규모 검증 |
| <b>5. 성과 화면</b> | 거래·쿠폰·현금·리밸런싱·성과분해 | NAV와 손익 기여도 대사 |
| <b>6. 액티브 전략</b> | 듀레이션 중립 벨리 확대 | 중립 포트폴리오 대비 효과 비교 |
| <b>7. 시장 화면 확장</b> | 거시·입찰·공급·상대가치 연결 | 투자 판단 기록과 연결 |

### 핵심 검증 항목

- 매수·매도 후 보유수량과 현금이 정확히 변하는가?
- 쿠폰 지급이 가격과 현금에 중복 반영되지 않는가?
- 금리 상승 시 고정금리 채권 가격이 하락하는가?
- 동일 규칙에서 KRD 합계가 평행 이동 민감도와 대체로 일치하는가?
- 일별 NAV 변화와 총손익이 일치하는가?
- 성과분해 항목 합계가 총손익과 일치하는가?
- 과거 시점에 공개되지 않은 자료를 사용하지 않았는가?

<b>첫 완성 목표:</b> 중립 복제 포트폴리오와 듀레이션을 맞춘 벨리 확대 포트폴리오를 비교하고, 성과 차이를 만기별 위험과 금리 변화로 설명한다.
