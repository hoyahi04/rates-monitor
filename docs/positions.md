# Tab 06 → Tab 07 포지션 규격 초안

전략과 리스크 담당이 먼저 아래 필드를 확인하고 샘플 데이터로 연결을 검증한다.

| 필드 | 정의 |
| --- | --- |
| signal_date | 신호 계산에 사용한 마지막 시장 관측일. YYYY-MM-DD |
| effective_date | 포지션 적용일. 일별 종가 데이터 기준 첫 버전은 신호일 다음 관측일 |
| strategy_id | 전략 식별자. 예시: 2s10s |
| tenor | 만기. 예시: 2Y, 10Y |
| target_dv01_usd_per_bp | 목표 포지션의 부호 있는 DV01. 금리가 1bp 하락할 때 예상되는 달러 손익. 롱은 양수 |

전략·적용일·만기당 한 행을 저장한다. 미보유 포지션은 0으로 명시한다.
일별 손익의 초기 검산식은 이전 관측일 종가에 적용한 DV01 × 다음 관측일까지의 금리 변동(bp) × −1이다.
캐리, 롤다운, 거래비용 및 비선형 효과는 별도 구현 범위로 둔다.
