## 자료를 만들며 확인한 것

- 재무부 종가(FedInvest)로 계산한 최근 발행물의 만기수익률이 재무부 par 금리(CMT)와 0.3bp 안에서 맞는다 (2년 4.623 대 4.63, 10년 4.920 대 4.92, 30년 5.310 대 5.31). 채권 계산식 검증으로 쓸 수 있다.
- FedInvest 종가는 하루 늦게 채워진다. 그래서 종목 표의 가격일(11-20)이 금리 기준일(11-23)보다 하루 이르다.
- 재무부 FiscalData의 예정 입찰 자료는 10월 중순에서 멈춰 있다 → 재무부 잠정 입찰 일정(XML)과 TreasuryDirect 공고로 바꿨다.
- BLS 사이트는 자동 접속을 막는다(403) → CPI·고용 발표일은 FRED 발표 달력 페이지에서 읽는다.
- FRED의 ICE BofA 스프레드 지수는 최근 3년치만 준다 (2023-11-24부터).
- 종목 싸고 비쌈: 2010년 이전에 발행된 옛 30년물 16개는 이웃 종목보다 금리가 10~20bp 낮거나 높게 나와, 추세선을 만들 때 뺐다.
- 모형 포트폴리오의 오늘 기준 듀레이션 차이는 +0.21년 (규칙상 +0.25년, 리밸런싱 뒤 시간이 지나 조금 줄어듦).

## 점검한 것 (2026-11-24)

- 채권 계산: `python3 pipeline/bondmath.py` 6개 항목 통과, `node assets/bondmath.js check` 5개 종목에서 파이썬과 같은 값.
- 화면 7개를 Chrome에서 띄워 콘솔 오류 0건. `?selftest=1`로 차트에 마우스 올리기, 표 누르기, 정렬, 필터 한 바퀴, 채권 상세·뉴스 열기까지 눌러 봄 (화면마다 18~178단계, 오류 0건).
- 어두운 화면, 폭 520px 화면 확인.
- 새 자료 수집이 전부 실패한 경우(원자료 폴더가 빈 경우)에도 자료가 만들어지고 화면이 "자료 없음"으로 뜨는 것 확인.
- 한국 경로는 가짜 자료(무작위 걸음, 프로젝트 밖에 둠)로만 화면을 띄워 봤다. 진짜 ECOS 자료로는 아직 확인하지 못함. ECOS 요청 형식은 시험용 키로 19개 시리즈 모두 확인.

확인하지 못한 것: Safari·Firefox, 실제 GitHub Pages 주소, GitHub Actions에서의 새 단계 실행 (로컬에서만 돌려 봄).

## 버전 2 (2026-11-24)

요청: "방금 이걸 version 1으로 만들고, duplicate 해서 테마만 살짝 바꿔봐. combined.html처럼 파란색, 좀 더 미니멀 버전으로."

- 버전 1 = `index.html` (그대로). 버전 2 = `v2.html` + `assets/theme-v2.css`.
- 폴더를 통째로 베끼지 않고 모양 파일만 따로 두었다. 자료와 화면 코드가 하나라 두 버전이 함께 갱신된다.
- 버전 2의 모양: 왼쪽 글자 메뉴(처음에는 위쪽 한 줄로 만들었다가 사용자 요청으로 왼쪽 기둥으로 바꿈. 아이콘 없이 글자만, 고른 메뉴에 파란 세로줄), 흰 바탕, 테두리 없는 회색 상자, 파란 강조 타일 하나, 파란 구역 제목, 가는 큰 숫자. 판정 점수는 combined.html처럼 파랑(0이 아님)과 남색(0) 상자.
- 공통 코드에 더한 것: 버전 표시와 전환 링크, 시간 순서 색(`--t1`~`--t4`: 오늘, 1주 전, 1달 전, 1년 전), 강조 타일 표시(홈의 10년 금리, 포트폴리오의 NAV). 버전 1의 모양은 바뀌지 않았다.
- 색: 선 색 네 개와 시간 순서 색(진한 파랑 → 연한 파랑)은 밝은 화면·어두운 화면 모두 색각 이상 검사를 통과한 값이다.
- 점검: 두 버전 모두 화면 7개에서 눌러 보기 점검 오류 0건. 버전 2의 어두운 화면, 폭 520px, 채권 상세 확인.
